# Uber Marketplace Optimization

## Project Overview
This project analyzes the trade-off between driver satisfaction and rider satisfaction in Uber's ride-sharing marketplace.

The goal is to identify pricing and wait-time combinations that balance the needs of both drivers and riders using Pareto frontier analysis.

## Objectives
- Compare driver and rider satisfaction.
- Identify efficient and dominated solutions.
- Evaluate different business strategies.
- Recommend a balanced approach to marketplace optimization.

## Dataset
This project uses a synthetic teaching dataset containing combinations of ride prices, wait times, driver satisfaction, and rider satisfaction. The data is illustrative and does not represent actual Uber operating data.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## How to Run
1. Download or clone this repository.
2. Make sure the notebook and `satisfaction_data.csv` are in the same folder.
3. Open `unit_10_notebook.ipynb` in Jupyter Notebook or VS Code.
4. Run all cells to view the analysis and results.

## Limitations
The analysis uses synthetic data and does not include actual Uber operating costs, profit margins, or real-world market conditions.
